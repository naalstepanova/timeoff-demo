# Leaveboard demo

Interactive demo of a time-off app built on Microsoft 365. All people and data are fictional.

Open `index.html` in a browser.

## Try this
1. As Jonas Keller, click "Request time off" and send a vacation request.
2. Switch to Hannah Weiss (manager) and approve it under Approvals.
3. Switch to Tomás Ribeiro (CEO) to give final approval.
4. Switch to Elena Varga (admin): book the Christmas closure for everyone, and set a last working day to see the final settlement.
5. Open Notifications to see what each person would receive.

Data resets on reload. Names and contact details are set in `CONFIG` at the top of the script.
